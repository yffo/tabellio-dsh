# 三分钟上手（普通用户向）

目标：装好、让它记住第一件事、再让它想起来一次。全程不需要改配置文件。

## 1. 安装并重启（约 1 分钟）

```bash
dsh plugin --profile desktop add tabellio-dsh
```

重启 DeepSeek Harness。打开 **设置 → 记忆**，第一次会看到一个三步小向导：

1. **智能记忆**：保持默认（开）。它会自动找本机的向量服务；找不到就只用关键词，不影响使用。
2. **服务位置**：本机有 Ollama/llama.cpp/LM Studio 就选「本机自动」；用云端 OpenAI 兼容服务就填地址、Key、模型（Key 只存在本地记忆库，界面只显示「已设置」）。
3. **存第一条**：可以跳过，也可以在向导里直接写一句。

## 2. 说一句「记住」（约 30 秒）

在对话里正常说话即可，不用背命令：

> 记住：这个项目发版都走 tag + GitHub Actions，不要再手动上传。

然后打开 **设置 → 记忆 → 待批准**：会看到一条候选。点「批准」入库；点「忽略」丢弃。
候选不会自动变成正式笔记——**批准权始终在人**。

什么会被记下来：

- 显式的「记住 / 以后都 / 别再…」
- 纠正句「不对，应该…」
- 陈述式约定「线上库只读」「周二发版」（按自动捕获档位）
- 可选的会话结论（默认关）

明文密码、token、密钥一律不写；一次性任务状态（「这次先用 8080」）默认不写。

## 3. 问一句，看它是否想起来（约 30 秒）

第二天再问：

> 我们发版流程是怎么定的？

回答时它会把相关记忆静默放到上下文里（不占对话）。想核对它到底用了什么：

- 标题栏的「🧠 记忆」胶囊 → 待批准数量 / 打开完整面板
- 概览 → 「上次召回」：查询、模式、条数、耗时、用了哪几条
- 概览 → 「最近 7 天」：召回次数、成本估算、裁决趋势

## 常用动作

| 想做的事 | 怎么做 |
| --- | --- |
| 找一条旧记忆 | 记忆库 → 搜索，点标题读全文 |
| 改一条记错的 | 打开笔记 → 编辑（旧文保留，可审计） |
| 删掉一条 | 打开笔记 → 忘掉这条（归档，不物理删除） |
| 调召回量/投递方式 | 设置 → 记忆 → 智能记忆 / 进阶设置 |
| 看看有没有漏记 | 概览 → 召回记录；或让 agent 用 `tabellio_inbox` |

## 它不会做什么

- 不会自动总结整段对话（另有可选的反思提案，默认关）
- 不会在未经批准时把候选写进正式笔记
- 不会把笔记上传到任何地方；库是本地纯文本
